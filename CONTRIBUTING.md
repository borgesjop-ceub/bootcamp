# Guia de Contribuição

Obrigado pelo interesse em contribuir com este projeto.

## Como contribuir

### 1. Abrir uma Issue

Antes de realizar qualquer alteração, abra uma Issue descrevendo o problema encontrado ou a melhoria proposta.

### 2. Criar uma Branch

Crie uma branch específica para sua alteração.

Exemplos:

feature/nova-funcionalidade

fix/correcao-de-bug

### 3. Realizar Alterações

Faça as alterações necessárias e teste o funcionamento antes de enviar.

### 4. Padrão de Commits

Utilize mensagens de commit claras seguindo o padrão:

- feat: nova funcionalidade
- fix: correção de erro
- docs: atualização de documentação
- chore: tarefas de manutenção

Exemplos:

feat: adiciona seção de certificados

fix: corrige link do LinkedIn

docs: atualiza README

### 5. Enviar Pull Request

Após concluir as alterações:

- Faça o push da branch.
- Abra um Pull Request para a branch main.
- Aguarde a revisão antes do merge.

## Boas Práticas

- Mantenha o código organizado.
- Documente alterações importantes.
- Respeite a estrutura existente do projeto.
- Teste suas alterações antes de enviar.

Obrigado por contribuir com o projeto!
